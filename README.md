# clic-silver-site — site de Clic Silver Digital Solutions

## Objectif
Le site vitrine de [clic-silver.com](https://clic-silver.com) : présentation de Clic Silver Digital Solutions, de ses prestations et de ses expertises,
avec un formulaire de contact. Site 100 % statique, construit par Astro, sans JavaScript livré au navigateur, publié sur GitHub Pages.

## Lancer en local
Avec Docker (aucune installation sur le poste ; la construction se fait dans l'image) :

```bash
docker compose up -d --build      # construit le site (Astro) puis le sert (nginx) : http://localhost:8080
docker compose down               # arrêter
```

Réglages facultatifs dans `.env` (défauts dans `.env.example`) : `VITRINE_PORT` (8080), `VITRINE_NOM`. Le port n'écoute que sur 127.0.0.1.

Sans Docker, avec Node 22.23.4 ou plus : `npm ci` puis `npm run dev` (développement) ou `npm run build` (sortie dans `dist/`).

## Publication
Chaque poussée sur `main` lance `.github/workflows/pages.yml`, qui construit le site et le publie sur GitHub Pages.
Le réglage du site (nom, contact, identité légale, navigation, réseaux) est dans `src/data/site.ts` ; les textes des pages de détail dans `src/data/pages-detail.ts`.
